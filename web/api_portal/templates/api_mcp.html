Claude Desktop

Open Settings - Developer - Edit Config (this opens claude_desktop_config.json), add the block below, then restart Claude Desktop. Replace YOUR_API_KEY with your key. 

{
  "mcpServers": {
    "tradewave": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "{{ mcp_url }}",
        "--header",
        "Authorization: Bearer YOUR_API_KEY"
      ]
    }
  }
}

ChatGPT

In ChatGPT (Settings - Connectors / a custom GPT with Actions), add a remote MCP connector with this URL and an Authorization header.

MCP server URL{{ mcp_url }}
Auth typeHTTP header
Header nameAuthorization
Header valueBearer YOUR_API_KEY

Cursor

Add to ~/.cursor/mcp.json (global) or .cursor/mcp.json in your project, then reload. Replace YOUR_API_KEY with your key. 

{
  "mcpServers": {
    "tradewave": {
      "url": "{{ mcp_url }}",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
