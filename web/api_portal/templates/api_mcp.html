Claude Desktop (BYOK)

Dev tools use your own API key. {% if has_key %}Use any active key from the API Keys tab.{% else %}You have no API key yet - create one first, then paste it in the configs below.{% endif %} Open Settings - Developer - Edit Config (this opens claude_desktop_config.json), add the block below, then restart Claude Desktop. Replace YOUR_API_KEY with your key. 

{
  "mcpServers": {
    "tradewave": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "{{ mcp_url }}",
        "--header",
        "Authorization: Bearer YOUR_API_KEY"
      ]
    }
  }
}
