Get started

The REST base URL is https://{{ api_host }}/v1. Authenticate every request with Authorization: Bearer <key>. Here is a call that lists your markets{% if new_raw_key %} - your new key is already filled in{% endif %}:

{# Tabbed so the snippet is copy-paste-correct on any platform. cURL is the universal one (bash / macOS / Linux / PowerShell 7). The PowerShell tab uses Invoke-RestMethod so it also works on Windows PowerShell 5.1, where `curl` is an alias for Invoke-WebRequest and rejects `-H`. ONE line per shell command (backslash continuations break on paste); the freshly created key is baked into all three. #} {% set example_key = new_raw_key or 'YOUR_API_KEY' %} 
curl https://{{ api_host }}/v1/markets -H "Authorization: Bearer {{ example_key }}"
Invoke-RestMethod "https://{{ api_host }}/v1/markets" -Headers @{ Authorization = "Bearer {{ example_key }}" }
import requests

r = requests.get(
    "https://{{ api_host }}/v1/markets",
    headers={"Authorization": "Bearer {{ example_key }}"},
)
print(r.json())
